MusicBrainz API

## What is it? Why might a designer care?

MusicBrainz is an open music database that offers information about different music artists, albums, recordings, and overall music related information.
Designers might care about this API because music data is universal and is needed all around the world. It can help designers create websites, apps, or any sort of experience relating to music, and this API can help designers through the process of helping people discover new artists, albums, and genres of music.

## Setup

1. Open Visual Studio Code
2. Install library requests: pip install requests
3. No API Key is required
4. Import Musicbrainz API endpoints: https://musicbrainz.org/ws/2/
5. Include the User Agent String in the format:
Application name/<version> ( contact-url )
or
Application name/<version> ( contact-email )

## One working code
## (filter 5 artists w/ Id with the name put by user input)

import requests

url = "https://musicbrainz.org/ws/2/artist"

params = {
    "query": 'artist:"Radiohead"',
    "fmt": "json",
    "limit": 5
}

headers = {
    "User-Agent": "StudentMusicDiscovery/1.0 (student project)"
}

response = requests.get(
    url,
    params=params,
    headers=headers,
    timeout=10
)

print("Status code:", response.status_code)

if response.status_code == 200:
    data = response.json()

    for artist in data.get("artists", []):
        print("Artist:", artist.get("name", "Unknown"))
        print("ID:", artist.get("id", "Unknown"))
        print()
else:
    print("The request failed. Please try again.")

## Gotchas

Rate Limits - one request per second or leads to blocked request

Missing Data - There is missing data on certain artists and music which can lead to errors (Use dictionary.get() to avoid missing fields)

Confusing Docs - specific search terms (ex: "query": 'artist:"Radiohead"')
               - MusicBrainz returns XML rather than JSON (Must add fmt=json to convert)
